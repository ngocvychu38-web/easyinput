# 直播工作室与硬件语音集成

日期：2026-09-21。状态：代码集成、自动回归与 Intel 应用构建完成；真实摄像头/开发板和声网双端验收待完成。

## 使用

1. 在 EasyInput 项目运行 `npm run tauri:dev`。脚本会尝试启动相邻的“直播软件”项目，固定使用 3002 端口；若该端口已有兼容服务，直接复用。
2. 使用打包应用时，先在 EasyInput 项目运行 `npm run live:dev` 并保持终端运行，再打开应用的“直播”。这个版本仍依赖外部 Vue/Node 项目，不是脱离直播源码和 Node 的独立安装包。源码不在相邻目录时，通过 `EASYINPUT_LIVE_PROJECT` 指定其路径。
3. 在 EasyInput 开始“实时对话”，确认开发板麦克风链路已连接，再打开“直播工作室”并开始本机预览。预览请求摄像头和电脑麦克风用于画面/直播音轨；桌面嵌入模式不再启动独立直播语音识别。
4. 对开发板说话后，实时对话识别出的用户最终转写会显示在直播画面字幕中；大模型回答不会传给直播页，也不会显示在画面字幕上。只有预览运行时显示字幕，停止预览后清空。
5. 对开发板说“戴上面具”“加上胡子”“变成猫咪”“取消贴纸”“美颜八十”可控制特效；实时对话用户转写触发一次对应动作。独立网页仍保留自己的原有识别方式。
6. 声网发布仍需有效 App ID、频道、匹配 UID 的 RTC Token。点击“保存 Token 到钥匙串”才持久化，后续可手动读取；所有模式均不再把 RTC Token 写入 localStorage。旧浏览器 Token 如存在，会保留在当前页面内存并从持久化配置移除，可在关闭页面前保存到钥匙串。
7. 观众链接包含 App ID 与频道，不含主播 Token/UID。其他电脑访问时需将 localhost 改为主播的局域网地址；启用声网鉴权时，观众仍须填写自己的有效 Token 和匹配 UID。未实现服务端 Token 签发。

开发预览地址：`http://localhost:1420/?page=live`。普通浏览器会明确标注硬件能力不可用；不能用它代替 Tauri 实板验收。

## 边界与原因

Vue 页面保留在外部直播项目，EasyInput React 壳通过受控 iframe 承载，避免重写已有摄像头、FaceUnity 和声网实现。新增 `EASYINPUT_EMBED=1` 服务模式允许受限宿主嵌入；默认独立模式继续使用 `X-Frame-Options: DENY`。

桌面嵌入模式的语音路径：开发板 16 kHz 单声道 PCM S16LE → EasyInput 实时对话会话 → `realtime-user-text` 用户最终转写事件 → 受限 iframe 消息桥 → 直播字幕/贴纸。模型回答没有传入这条消息通路。直播预览不会另开 `live-speech` 会话；硬件仍只负责采集与 EICC/EICA 控制，不需要新增固件报文。独立网页模式保持原有识别方式。

桌面嵌入直播不再启动独立直播 ASR，也不使用电脑麦克风做语音识别。字幕和贴纸动作共用实时对话的用户最终转写；宿主消息经 `LIVE_PROTOCOL`、精确 origin/source、clientId/token 校验后传入直播页，并复用 `applyFromSpeech`。触发贴纸的实时语音指令在 Rust 侧作为本地动作处理并取消模型同轮回答；字幕仍仅显示用户原话。RTC 发流时电脑麦克风音轨保持原样。

实时通话控制示例：“蓝色面具 / 戴上面具”“胡子 / 加点胡子”“猫咪 / 变成猫”“圣诞老人帽”“帽子和墨镜”“取消贴纸”。转写来源是 EasyInput 实时对话中的开发板语音链路，不调用电脑浏览器麦克风；贴纸由直播页现有函数切换，并同步保存所选状态。

观众听到的声音仍来自直播项目原有电脑麦克风音轨；本次仅复用开发板作为识别输入。开发板声音没有接入声网音轨。

## 消息与生命周期契约

宿主只接受 `http://localhost:3002` 且 source 是当前 iframe 的消息。子页只接受列举的 EasyInput 开发/原生来源及 parent 窗口。协议为 `easyinput-live-v1`，握手绑定随机 clientId 和宿主 token，请求带 requestId 去重。

| 操作 | 行为 |
|---|---|
| `loadRtcToken` / `saveRtcToken` | 仅访问直播专用 Keychain 项，不提供任意账户名或任意 IPC |

实时语音用户转写以受限 `user-utterance` 消息发送，携带识别文本与受限控制标志；大模型输出事件不在协议内。消息桥校验 parent origin、窗口、clientId 和 token。

嵌入模式直接返回硬件识别分支，不启动 SpeechRecognition、Web Audio ASR 上行或 Node `/speech`。独立网页仍保留原识别流程。

退出时立即停止本地媒体轨道和 AR；声网销毁等待进行中的 join 结束再 leave，避免离页后连接重新出现。不会自动点击“发布到声网”。
