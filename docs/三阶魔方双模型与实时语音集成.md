# 三阶魔方双模型与实时语音集成

EasyInput 增加一个默认隐藏的“魔方”模块，复用相邻项目 `/Users/macforai/Documents/ChatGPT/三阶魔方09241/` 的双盘页面。实时通话最终识别到“打开魔方”后才展示并加载页面；语音“关闭魔方”会返回概览并从导航隐藏。

## 语音操作

- “打开魔方”：打开 Jev 与 DeepSeek Flash 并排的双模型页面。
- “同步重新打乱/打乱魔方”：直接触发双盘页面右上角现有“同步重新打乱”按钮，让两边播放同一组 20 步公式。
- “一键完成七步/一起开始复原魔方”：同时点击两边各自的“一键完成七步”按钮。每边仍由自己的模型选择本盘安全候选；缺少 API Key 或当前状态不可复原时，该边会沿用现有错误与保护行为。
- “关闭魔方”：隐藏模块并返回概览。

打开/关闭模块以及打乱或复原控制均在 Rust 侧识别为本地处理并取消同轮模型回复，避免模型把魔方当成待启动的软件。打乱或复原控制只在魔方页面已打开时执行。语音指令通过 EasyInput 的最终转写本地事件识别，不由云端 Function Calling 构造任意页面消息。

## 进程与安全边界

魔方页面由 `三阶魔方09241/server.js` 在本机 `127.0.0.1:8787` 提供。`npm run tauri:dev` 会自动启动缺失的魔方服务，退出开发应用时清理由该脚本启动的进程；也可单独运行 `npm run cube:dev`。生产包使用时需另外启动该服务。

EasyInput 和双盘容器使用带随机 token 的 `postMessage` 握手，并检查准确的 iframe 来源与窗口引用。握手使用双盘容器提供的 peer ID；容器会重试 hello，且主动 ping 两个子魔方确认 ready，避免消息早于监听器而丢失。Jev / DeepSeek API Key 分别保存在 macOS Keychain；打开魔方时按 provider 送入对应子页面，输入或修改后自动保存。升级前已存在的浏览器本地 Key 只在对应 Keychain 项为空时迁移。密钥只经本机页面内存与受限 iframe 消息桥传递，不进入实时语音、普通配置文件或诊断日志；模型 API 请求仍由魔方原有页面直接发送给原有服务。页面继续执行原有候选校验、状态版本检查和七步完成判定。

完整实现与算法边界以三阶魔方项目的 `docs/实现过程与原理.md` 为准。
