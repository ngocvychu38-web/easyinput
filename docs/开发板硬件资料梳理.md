# EasyInput 开发板硬件资料梳理

更新时间：2026-09-24  
范围：基于 EasyInput 仓库内现有客户端、固件接口和集成文档梳理；不代表已拿到开发板原理图或固件工程。

## 结论摘要

- 仓库能说明开发板与 Mac 客户端之间的 USB HID、Wi-Fi UDP 控制和 PCM 音频接口，以及现有实板协议探针结论。
- 仓库未发现开发板原理图、PCB 工程、GPIO/管脚表、BOM、器件规格书或固件源码。因此 MCU/模组型号、GPIO 编号和复用、供电树、音频 codec/I2S 接线、天线/射频设计、器件料号/替代料均无法从当前资料确认。
- 下文的“已知硬件信息”限于软件接口契约；不能据此推断板上引脚或电路实现。

## 系统边界与板卡职责

| 部分 | 当前资料明确的职责 |
|---|---|
| 开发板固件 | 实时通话按键触发；USB HID；设备就绪心跳；接收 Start/Keepalive/Stop；采集麦克风 PCM 并通过 UDP 上行；接收 UDP PCM 并经板载音频链路播放 |
| EasyInput Mac 客户端 | USB 设备发现与按键动作；UDP 会话与协议校验；ASR/实时语音服务调用；文本动作和页面控制 |
| 外部云服务 | 豆包实时语音或 ASR。固件不解析云服务协议、不持有 API 凭据 |

项目明确不包含固件源码；驾驶舱 Function Calling 与直播字幕等功能主要由客户端实现，当前没有为这些功能新增固件业务协议。参见 [客户端与固件接口说明](语音调用-客户端与固件接口说明.md)、[驾驶舱固件要求](开发板实时语音直控驾驶舱-固件要求.md)。

## 已知接口与参数

### USB HID

客户端通过 USB HID 识别键盘/控制器并接收标准键盘报告或固件 App Command。实时通话触发推荐 `EasyInputRealtime` App Command，兼容触发是 `Ctrl+Shift+R`；编辑/按键配置另有 USB Feature Report 协议。上述信息描述主机可见协议，不提供 USB 芯片、接口电路或 MCU 引脚映射。

### Wi-Fi 与 UDP 音频

- 开发板与 Mac 在可互通的局域网内。音频目标主机及端口由客户端 Wi-Fi 配置提供；默认 UDP 端口为 `17333`。
- `EIHB` v1：设备就绪心跳，建议每约 1 秒发送；客户端最多等待 7 秒发现设备。
- `EICC` v1 / `EICA` v1：Start、Keepalive、Stop 控制及 ACK；Start ACK 超时为 3 秒。
- `EIAU` v2：板到 Mac，16 kHz、单声道、PCM S16LE；每帧 20 ms / 320 samples / 640-byte PCM，加 32-byte 头，共 672 bytes。
- `EISP` v1：Mac 到板，24 kHz、单声道、PCM S16LE；每帧 20 ms / 480 samples / 960-byte PCM，加 32-byte 头，共 992 bytes。
- 协议整数使用小端序；会话 ID 与序列号用于隔离会话和检测包顺序。

### 音频硬件（仅为固件接口要求）

固件需要提供麦克风采集、扬声器播放和双向 PCM 传输。项目建议用扬声器参考信号实现 AEC，并记录 I2S 错误、丢帧、乱序和欠载。但现有仓库没有说明使用哪颗 codec、数字麦克风或 DAC/功放，也没有提供 I2S/I2C 引脚、采样时钟、增益、供电和 AEC 实际启用状态。

## GPIO / 管脚信息现状

目前没有可核实的 GPIO 编号、封装管脚号、信号名、方向、上拉/下拉、电平、复用功能、外接器件或启动绑带状态。软件接口中出现的 USB、Wi-Fi、PCM、I2S 等名词不能映射为芯片 GPIO。

需要硬件/固件团队提供至少如下 pin map：`信号名 | MCU/模组管脚号 | GPIO 编号 | 方向 | 空闲/有效电平 | 上拉/下拉 | 复用功能 | 外设/连接器 | 备注`。同时标注板卡版本与原理图页码，避免不同 PCB revision 混用。

## 原理图与 BOM 现状

仓库文件检索未发现常见原理图/PCB 工程（如 KiCad、Altium 导出）、PDF 原理图或 BOM 表格。故目前不能可靠列出：

- 主控/无线模组的具体型号、Flash/PSRAM 容量与天线方案；
- USB 接口、ESD/过流保护、充电/电池/稳压电源链路；
- 麦克风、音频编解码器、扬声器驱动与音频时钟电路；
- 按键、旋钮、指示灯及其 GPIO；
- PCB 版本、关键器件位号、制造商料号、封装、数量、替代料及采购状态。

补齐 BOM 时建议字段：`位号 | 数量 | 器件类别 | 制造商 | MPN | 封装 | 关键参数 | 替代料/约束 | 采购备注 | 对应原理图页`。请同时给出板卡硬件版本/修订号，BOM 与原理图需属于同一版次。

## 实板验证记录（仓库已有）

2026-09-21 的直播硬件协议探针记录：`startAck=true`、`stopAck=true`、收到有效帧 `297`、音频来自独立 UDP 源端口、序号缺口 `3`。这能证明当时连接的设备与客户端协议互通，不能证明电路原理、GPIO 分配、BOM 或长期音质指标。参见 [直播工作室与硬件语音集成](直播工作室与硬件语音集成.md)。

请从开发板硬件/固件项目提供并注明版本：

1. 原理图 PDF（可搜索文字）及源工程，PCB 版本、板号和修订记录。

3. GPIO/pin mux 表，覆盖 USB、按键、音频/I2S/I2C、状态灯、复位/启动脚及扩展接口。

5. 对应固件版本/提交、板卡版本，以及实际测得的电压、接口和音频验收记录。
