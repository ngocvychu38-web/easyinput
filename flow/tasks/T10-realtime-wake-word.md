# T10 · 实时语音唤醒词待命

- **背景**：实时语音聊天同时负责回答和控制软件；用户需要在不结束通话的情况下让助手暂时安静，并在再次呼叫后恢复。
- **目标**：提供可选的本次通话唤醒词模式；休息指令后保留语音识别以监听唤醒词，但不回答、不执行本地动作或 Function Calling。
- **触发语句**：休息指令包括“闭嘴吧”“请你休息一下”等相近表达；唤醒词为“八弟八弟”，兼容常见近音识别文本。唤醒词后的同一句任务内容继续处理。
- **实现边界**：唤醒状态与语音动作门控放在 Rust 实时会话；React 通话页默认开启，可在通话前和通话中切换，并显示状态；关闭开关时保留原始通话行为。待命后麦克风音频持续上传识别，普通话语被丢弃；单说唤醒词只解除待命，不要求助手先回应，后续任务正常处理。宿主直接关闭子模块时由客户端执行并取消同轮模型输出。
- **验收标准**：检查开关关闭时既有语音行为不变；开启后休息指令取消当前回答并阻止回答/软件控制；待命中普通话语无响应；“八弟八弟”及近音转写唤醒；“八弟八弟，打开……”同轮处理后续命令；前端/Rust IPC 状态契约同步。
- **验证**：既有诊断日志确认复现会话启动时 `wakeWordEnabled=false`，且 ASR 把唤醒词识别成“巴蒂巴迪”近音。最新默认开启和近音兼容调整后，待 `npm run build`、`cargo check --manifest-path src-tauri/Cargo.toml` 验证；未运行测试套件；真实开发板语音端到端尚未验收。
- **状态**：代码实现完成，实板验收待完成。
