# T09 · 直播工作室整合与实时对话字幕

- **背景**：用户要求将 `/Users/macforai/Documents/ChatGPT/直播软件/` 功能整合进 EasyInput，语音识别复用现有硬件。
- **目标**：提供完整直播工作室入口；嵌入桌面版的字幕与特效统一使用 EasyInput 实时对话的开发板用户语音事件。
- **语音契约**：只将实时会话的用户最终转写传给直播页；模型回答不得成为画面字幕。贴纸/美颜命令复用直播页既有动作逻辑；实时命令在同轮抑制模型回复，不开放任意页面脚本或 Tauri 命令。
- **输入**：直播 `src/App.vue`、`src/nama/`、`server/`；EasyInput 实时通话转写事件、硬件音频传输、受限 iframe 消息桥与 Keychain。
- **产出**：宿主导航和直播页、用户转写消息桥、贴纸/美颜动作映射、启动支持及验收说明。嵌入模式不启动额外直播 ASR；独立网页保留原识别行为。
- **验收标准**：画面字幕只显示开发板用户原话、不显示模型回答；实时转写驱动贴纸与美颜；没有电脑浏览器语音识别、文字注入或全局动作；桥接仅允许当前 parent origin/source/clientId/token；前后端构建通过，实板结果如实记录。
- **状态**：实现和两项目构建完成；待开发板实时对话字幕、特效映射及声网双端实机验收。参见 `docs/直播工作室与硬件语音集成.md` 的已验证与待验证清单。
